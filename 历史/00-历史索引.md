## 恢复方法

```sh
# 查看包内清单
tar -tzf 历史/备份-2026-11-15.tar.gz

# 恢复到临时目录（不要直接解到仓库根）
mkdir -p /tmp/charlotte-history && tar -xzf 历史/备份-2026-11-15.tar.gz -C /tmp/charlotte-history

# 或从整理前 git 快照取单个文件
git show 49d7649:backups/pre-0.6.0/lib/types.js > /tmp/types.js
git show 49d7649:README.revamp.md > /tmp/README.revamp.md
```

- 旧版本只进本目录的 `*.tar.gz`，不允许散落 `.bak`、`*.before-publish`、`*_backup*`。
